## Patient Questionnaire App
This app is developed using React, redux, typescript, Nextjs and the backend data is stored in Vercel neon db using Nextjs server components. This questionnaire app aims at collecting patient information from user and this can be used by doctors for evaluation.
## Features
1. Create user and JWT based user authentication with in memory storage
2. Patient Personal information
3. Medical History
4. Health questions
5. Homepage to display patient informations

## Clone the repository
(https://github.com/sindumathi/hars_health_dpc.git)
##  Navigate to the project
    cd hars_health_dpc
## Install dependencies
    npm install
    Create a vercel neon postgres database and create .env file with credentials to run this app locally.
## Start the development server
    npm run dev
    The application will be available at the local URL:   http://localhost: 3000
## Production Build
    To create an optimized production build:
      npm run build
    To preview the production build locally:
      npm run preview
